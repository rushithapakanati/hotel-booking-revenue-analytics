# Hotel Booking & Revenue Analytics | Power BI

## Project Overview
This project analyzes hotel booking operations and revenue performance using Microsoft Power BI. The dashboard provides an interactive view of booking trends, hotel revenue, guest activity, stay patterns, and customer booking preferences.

## Objectives
- Monitor key hotel booking and revenue KPIs.
- Analyze monthly booking trends.
- Compare revenue performance across hotels.
- Understand booking channel and room-type distributions.
- Explore guest loyalty-tier distribution.
- Support data-driven operational decisions through interactive reporting.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Modeling and Relationships
- Interactive Data Visualization

## Key Dashboard Features
- **KPI Cards:** Total Revenue, Total Bookings, Total Guests, Total Stays, Total Nights Stayed, and Average Booking Value.
- **Booking Trends:** Monthly booking analysis.
- **Revenue Analysis:** Revenue comparison across hotels.
- **Stay Analysis:** Stay status distribution.
- **Booking Behaviour:** Booking channels and requested room types.
- **Guest Analysis:** Loyalty-tier distribution.
- **Interactive Filters:** Booking date, hotel, and booking channel.

## Business Value
The dashboard helps users explore booking patterns, compare hotel revenue performance, understand customer booking preferences, and identify areas for further operational analysis.

## Project Outcome
This project demonstrates practical skills in Power BI dashboard development, data transformation, DAX calculations, relationship modeling, and business analytics.
